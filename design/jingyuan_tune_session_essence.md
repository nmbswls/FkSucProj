# 调精：长线固定 → 临时单局养成（设计草案）

## 1. 目标（已对齐的方向）

调精不是永久叠强度，而是：

1. **据点内**用原料做提炼/调配，产出带**浓度**的优质精华；  
2. **出门前**装入**出行匣**并锁定；  
3. **外出期间不能改匣**——匣内配置决定本趟的战利品收获与即时效果；  
4. 每种精型的优质精华按浓度给效果；后期可做**混合联动**。

「单局」在此主要指：**外出这一趟的构筑锁定 + 精华时效**，不是清档。

---

## 2. 双层结构：据点工坊 vs 出行匣

### 2.0 对「出行匣 3～5」的修正（已否决作唯一容器）

把出行匣做成 **3～5 格总容量** 撑不起匣内玩法，原因很具体：

1. **构筑维度不够**：浓度档 × 精型 × 预留混合位，3～5 格几乎没有「搭配」空间，只剩带 3 个按钮出门。  
2. **战利品无处去**：外出锁定的是**操作**（不能提纯/改生效位），不是「本趟不能进货」。战利品（粗精、低浓度成品）仍要进匣；3～5 格会在第一次收获后就满，逼玩家不停丢，和「带配方去收割」矛盾。  
3. **锁定的正确含义**：外出禁止**改构筑与工坊操作**；允许**只进不出地装战利品**（或仅允许丢弃腾位），需要足够空位。

因此出行匣必须按「**出发构筑 + 本趟收获仓**」做**中大容量**，不能用装备槽体量冒充匣体量。

```text
据点（可完整操作）                      外出（操作锁定）
┌──────────────────────────┐          ┌────────────────────────────┐
│ 工坊：提纯/浓缩/混合      │  装匣    │ 出行匣（建议 12～20）       │
│ 原料（背包堆叠）          │ ──────►  │ · 出发时装好的生效精华      │
│ 工坊暂存/未装匣成品       │          │ · 预留空位接本趟战利品      │
└──────────────────────────┘          │ · 不可改生效/不可工坊操作   │
         ▲                            └────────────────────────────┘
         └──────── 回据点卸匣、再提炼 ─────────────┘
```

| 容器 | 何时可改 | 职责 |
|------|----------|------|
| **工坊**（据点） | 仅据点 | 原料→高浓度；混合实验；决定「装哪些进匣」 |
| **出行匣**（中大） | 出门前自由整理；**外出后禁止改生效与提炼**，仍可收入战利品 | 本趟效果 + 收获修正 + **本趟战利品库存** |

### 2.0.1 匣内建议再拆「逻辑槽」，而不是只砍总格数

总格数要大；**玩法深度**靠匣内分区，而不是靠把总容量砍到 3～5：

| 分区 | 建议格数 | 外出时 | 作用 |
|------|----------|--------|------|
| **调律位（生效）** | 2～4 | 锁定，不可换 | 决定本趟被动/属性 + 收获公式权重 |
| **收获仓（战利品）** | 其余（如总 16 则约 12+） | 只进（或可丢不可装生效） | 接粗精/低浓度精华，撑满一趟回收 |
| **（可选）触媒位** | 0～1 | 锁定 | 本趟全局倍率/稳定，丰富构筑而不占很多格 |

玩家感知：「我带了 16 格匣出门」——其中只有 2～4 个是本趟**调律**，其余是为收割留的肚子。  
之前误把「调律位 3～5」写成了「整匣 3～5」，这才是不合理之处。

## 3. 玩法主轴：原料 → 操作 → 高浓度精华

### 3.1 物品分层（建议三层，避免全塞进「优质精华」）

| 层级 | 名称（暂定） | 存放 | 保质期 | 作用 |
|------|--------------|------|--------|------|
| L0 | 普通精元 `jingyuan` 等 | 普通背包 | 无/弱 | 货币、精浴、粗燃料 |
| L1 | **粗精 / 精渣原料** | 普通背包或「原料格」 | 可较短 | 工坊投入物；外出用匣收获可提高粗精掉率 |
| L2 | **优质精华（成品）** | 工坊库存 → 装入出行匣 | 有 | 按精型 + **浓度** 提供效果；可混合 |

外出收获的主产物应是 **L1 粗精/原料**（以及少量低浓度 L2），高浓度 L2 主要靠**回据点操作**获得——这样工坊才有事做，而不是野外直接毕业。

### 3.2 工坊操作（第一期建议只做 2～3 个）

| 操作 | 输入 | 输出 | 设计作用 |
|------|------|------|----------|
| **提纯** | 同精型粗精 ×N | 同精型精华，浓度↑，数量↓ | 核心：把量变成质 |
| **浓缩** | 低浓度精华 + 燃料/触媒 | 浓度再↑，保质期可能缩短 | 高风险高回报 |
| **稳定** | 精华 + 稳定剂 | 保质期延长，浓度略降或不变 | 给「带远门」的解 |
| **混合**（二期） | 精华 A + B（规则表） | 混合精华或联动 buff | 深度与图鉴联动 |

浓度建议用离散档（如 1～5 或 10/30/60/100），对接现有 `JingYuanTuneTier` 的档位思路，而不是无限浮点。

### 3.3 效果如何挂浓度

- **单精型**：`效果 = f(精型, 浓度档)`（属性、被动技能、特殊收获修正）  
- **出行匣多格**：  
  - 各自独立生效（简单）；或  
  - 同匣内满足 tag 组合触发**联动**（二期）  
- **收获修正（关键）**：匣内精型/浓度影响本趟  
  - 对应精型粗精掉率  
  - 特定交互额外产出  
  - 稀有精型「遇见权重」  
  → 兑现「出行匣决定战利品收获」

现有长线 `TiaoJingConcentration` 全局浓度建议**降权或并入单条精华浓度**，避免「全局一条浓度条」与「每条精华自己的浓度」双轨。

## 4. 12～16 格撑不撑得起？——结论：只当成品仓偏紧，当工坊缓存可以

取决于 12～16 装的是什么：

| 若 12～16 只装成品优质精华 | 评价 |
|---------------------------|------|
| 精型种类一旦到 8+，再留提纯中间物、混合试作 | **偏紧**，玩家会频繁扔/卖，工坊深度吃瘪 |
| 仅 4～6 种前期精型，且半成品不占格（堆叠原料） | **勉强够**第一期 |

| 若拆成「原料不占精华格」 | 评价 |
|--------------------------|------|
| L1 粗精走**普通背包堆叠**或独立原料页 | 12～16 专装 L2 成品/半成品 → **够撑提纯玩法** |
| 出行匣另计 3～5，不占 12～16 | 结构清晰 |

**推荐容量模型（修正后）：**

| 容器 | 建议 | 说明 |
|------|------|------|
| 普通背包 | 继续堆 L0/L1 | 原料要「多」，用堆叠 |
| 工坊暂存 | 可选；或与匣共用整理台 | 据点提纯工作台，不必再维持一个巨大「第二仓库」 |
| **出行匣总容量** | **12～20**（推荐先 **16**） | 含调律位 + 收获仓；外出锁定的是操作，不是「只有 3 格」 |
| **其中调律位** | **2～4** | 真正决定本趟效果与收获权重的「内部玩法」核心位 |
| **其中收获仓** | 总容量 − 调律位 | 撑一趟战利品；满则掉地/拒收策略见前 |

要点：

- **匣要大**，大在收获仓与出发前的挑选空间；  
- **调律位要少而精**，少在生效维度，好做浓度/混合权重，而不是把整匣砍成 3～5；  
- 不可堆叠实例仍吃格：高浓度成品主要占调律位；野外粗精尽量堆叠进收获仓或普通背包，避免收获仓瞬间爆满。

## 5. 外出锁定与收获闭环（示例）

1. 据点：提纯出高浓度精华，装入**调律位**（2～4）；匣内其余格留空给收获。  
2. 确认出门 → **调律锁定** + 工坊禁用；UI 显示本趟收获预览。  
3. 野外：产出进**收获仓**/背包；调律位精型提高对应粗精；不开放改调律、不开放提纯。  
4. 收获仓满：新战利品掉地或短时脚边可捡（不解锁调律）。  
5. 回据点：解锁；收获仓卸到工坊/背包；再提纯；过期清理。
---

## 6. 混合联动（二期预留，一期勿做满）

配置向，例如：

- `tag_a + tag_b` → 额外被动 / 额外收获类型  
- 同匣内浓度总和达阈值 → 临时「调精领域」  

一期只需：单精型浓度档 + 匣位加成收获；数据结构预留 `mixture_id` / `link_tags` 即可。

## 7. 数据形态：Item 实例 vs「全新结构」（修正）

装备也是物品：`item_id` + 强化/词条/耐久等实例字段。优质精华同理，**不必**为了「有浓度/过期」就否定 Item 路线。

更准确的二分是：

| 方案 | 含义 | 何时合适 |
|------|------|----------|
| **A. 物品 + 实例载荷** | 仍走道具/袋子系统；每条精华是不可（或难）堆叠的实例 Item（含 concentration、expireAt、codexId） | 希望复用给予、存档、袋、丢弃、UI 格子；和装备同一心智 |
| **B. 独立运行时结构** | 完全自建 `PremiumEssenceInstance` + 专用匣 | 几乎不与道具系统交互、要强隔离权限时 |

**修正倾向：优先 A（物品实例）**，专用的是「调精袋/出行匣容器与规则」，不是否定「它是物品」。  
独立结构只作为实现细节（若现有 `ItemStack` 扩不动再抽），对玩家仍呈现为调精袋里的物品。

### 7.1 落地掉落 vs 软上限（你提的方案）

**可以不做落地，改为：一定进包 + 软上限。**

规则草案：

1. 获得优质精华时**一律进调精袋/出行匣**（不进普通背包，或进但标记为调精专用袋）。  
2. 袋有**硬展示格**（如 16）与**软溢出区**（逻辑上仍持有，UI 标红「未整理」）。  
3. 溢出部分若在时限内（如 N 分钟 / 半个游戏日）未被装入正式格、丢弃或提纯消耗 → **自动销毁**并醒目提示。  
4. 外出锁定调律时：新进精华只进收获仓/溢出区，不能改调律位。

这样是否合理？**合理，且更贴「装备式物品」心智**，还能避免满地精华。

注意点：

- 软上限必须**强提示**（否则变成隐形删档愤怒点）。  
- 溢出区不宜无限：建议软上限 = 硬格 + 额外 4～8，再多直接拒收或立刻进销毁倒计时。  
- 「自然保质期」与「溢出销毁倒计时」可并存：溢出倒计时更短，逼整理；正式格内只走正常保质期。  
- 主动丢弃：若不做落地，就用确认销毁；若以后要落地再加，不是一期必需。

### 7.2 获得与丢弃提示

- 获得 L2：专用醒目 toast（浓度 + 过期 + 占用/溢出状态）。  
- 进入溢出：更醒目警告「未整理，将在 xx 后消散」。  
- 溢出销毁 / 自然过期：提示，不落地。  
- L1 原料：普通或弱一档提示即可。

## 9. 阶段建议

**一期**  
- 双容器：工坊库存 + 出行匣锁定  
- L1 粗精（背包堆叠）→ 提纯 → L2 浓度档  
- 匣影响对应精型收获  
- 醒目获得提示  

**二期**  
- 浓缩/稳定、混合联动、匣位组合  
- 工坊容量成长、触媒配方
