# 人类文明与科技系统方案：home_01 首城版

## 1. 方案目标

本系统承接三类内容：

1. 城镇建筑的升级、经营方向和地方特色。
2. 以人类通识为通用知识货币、以专精知识为关键门槛的科技节点。
3. 搜刮物、城镇产出、加工品、贸易、潜入和区域安定之间的循环。

首城 `home_01` 不承担完整文明树。它应让玩家理解：搜刮物可以交给人类社会鉴定、加工或交易，换成金钱、通识、秘闻和影响力，再反过来改善探索。

## 2. 核心资源分工

### 2.1 人类通识

人类通识是科技系统的通用知识货币，不直接作为普通商店货币使用。

来源：

- 酒馆经营产出。
- 与重要 NPC 交流、完成教学或调查任务。
- 捐献人类书籍、教会抄本、工艺品和部分高质量搜刮物。
- 首次发现人类建筑、设施或制度时获得少量一次性奖励。

用途：

- 解锁通用科技节点。
- 解锁建筑能力和经营方案。
- 解锁贸易、加工、建筑管理等功能。
- 提供少量稳定的城镇或探索增益。

通识表示文明接入程度，不应成为可以无限刷出的普通材料。首城早期产量应低，主要通过酒馆、任务和首次发现获得。

### 2.2 专精知识

专精知识代表某个行业的实际能力，例如木工、纺织、炼金、石工、烹饪和贸易。

专精知识继续使用现有道具，不新增“科技点”概念。它作为关键科技节点的专业门槛：

```text
通用节点：主要消耗人类通识
行业节点：人类通识 + 对应专精知识
高阶建筑或地方特色：专精知识 + 建筑等级、NPC 或任务条件
```

### 2.3 金钱

金钱是贸易货币，主要用于通用贸易、基础补给、加工辅料和部分建筑运营成本。

金钱不建议直接用于解锁全部科技，否则科技会退化为商店消费，搜刮物的独特性也会被削弱。

### 2.4 影响力

影响力是城镇经营资源，由经营和城镇建设产生，不应直接从野外搜刮获得。

影响力表示城镇对居民、商队和周边区域的号召力。它可以用于：

- 提高城镇控制度或区域安定项目的推进速度。
- 提升贸易上限、委托数量或加工岗位数量。
- 解锁对探索有帮助的区域性支持。

影响力不作为玩家背包物品，而保存于城镇或区域状态中。不同城镇应分别拥有自己的影响力。

## 3. 系统结构

### 3.1 建筑层：等级与经营方案

建筑层直接作用于某个城镇的某栋建筑，属于局部投资。

建筑拥有：

- 当前等级。
- 基础产出或服务。
- 可选经营方案槽位。
- 地方特性标签。
- NPC、人口或投入物需求。

建筑升级解决“这栋建筑变强了什么”，例如提升产量、容量、岗位或服务质量。经营方案解决“这栋建筑当前怎么工作”，例如酒馆选择偏通识还是偏秘闻，木工棚选择批量加工还是低消耗加工。

建筑升级和经营方案是两个操作，但都放在具体建筑详情页。

### 3.2 科技层：跨城镇的人类文明进展

科技节点是玩家永久解锁的文明能力。它不需要玩家在每座城镇反复管理，也不需要每日切换。

建议首期分为四条分支：

1. `社会组织`：城镇管理、影响力、控制度和安定辐射。
2. `贸易与账册`：搜刮物兑换、通用贸易、商队和价格信息。
3. `工坊技术`：加工建筑、二级产物和制作链。
4. `情报与潜入`：酒馆秘闻、潜入辅助、警戒预警和区域情报。

科技节点的效果可以作用于全局、某类建筑或满足条件的城镇。例如：

- `基础账册`：解锁搜刮物估价和手动兑换。
- `酒馆识字`：解锁酒馆的人类通识产出。
- `工匠分工`：解锁加工建筑的经营方案。
- `地方安定`：解锁城镇安定和周边辐射。
- `巡路制度`：所有已控制城镇的安定辐射略微提高。

所有永久生效、无需选择和维护的宏观效果，都直接作为科技节点处理。

## 4. home_01 的定位

`home_01` 是魔雾边缘的贫困聚居地，拥有有限的人力、简陋的贸易网络和一间勉强运转的酒馆。

首城只承载：

- 基础搜刮物兑换金钱。
- 酒馆产出少量人类通识和秘闻。
- 基础木材、石材和纺织物加工。
- 基础影响力产出。
- 初级城镇安定和周边探索支持。
- 一至两个需要中间产物献祭或交付的地图/角色解锁。

首城不应成为所有生产和情报功能的终点。

## 5. 首城开放顺序

### 阶段 0：抵达与认识城镇

开放：

- 城镇总览。
- 城镇控制度、安定和影响力查看。
- 建筑等级查看。
- 重要 NPC 对通识和专精知识的解释。

建议承载 NPC：城镇管理者、酒馆负责人和工匠负责人。三人可以是有名字的重要 NPC，但不需要展示完整镇民名单。

### 阶段 1：商亭与搜刮物兑换

开放：

- 选择背包或仓库中的搜刮物。
- 查看估价、推荐用途和稀有度。
- 手动确认兑换金钱。
- 查看“建议保留”“可加工”“可交易”等提示。

稀有工艺品、教会物品和独特任务物品默认不进入普通兑换列表，或必须由玩家明确确认。搜刮物不自动转化为通用资源。

### 阶段 2：酒馆与人类通识

开放：

- 酒馆每日产出少量人类通识。
- 酒馆每日产出少量秘闻或潜入情报。
- 捐献书籍、抄本和工艺品，获得一次性通识。
- 解锁第一个科技节点，如 `基础账册` 或 `酒馆识字`。

通识是稳定、低量、可预期的产出；秘闻是低量、带随机性或区域关联的产出。两者都来自酒馆，但不合并为一种资源。

### 阶段 3：基础城镇管理

完成首个建设或控制任务后，开放：

- 基础影响力产出。
- 建筑升级。
- 建筑经营方案。
- 城镇安定显示和变化来源。
- `社会组织` 分支的第一个科技节点。

城镇的宏观效果通过科技节点、建筑等级、建筑经营方案和地方特性产生。

### 阶段 4：木工棚与基础加工

先开放木工，再开放其他加工建筑。

木工棚建议承接：

- 基础木料 -> 木板。
- 基础木料 -> 木柄或简易构件。
- 木料类搜刮物 -> 可用于建筑的基础材料。

木工棚的意义不是把所有搜刮物变成通用木材，而是让一部分搜刮物获得新的用途。原始物品仍保留名称、品质和来源。

石工和纺织加工作为第二轮开放：

- 石材 -> 砖、磨石和建筑构件。
- 纤维/布料 -> 绳、包裹材料和基础纺织品。

### 阶段 5：献祭造物与新地图入口

首城中后期开放一个“人类造物交付/献祭”功能，由重要恶魔角色或特殊地点承载。

交付物应是具有明确文明含义的二级产物，而不是单纯金钱。交付后解锁新地图、区域通行资格或特殊角色。关键材料仍需通过搜刮获得，形成：

```text
探索 -> 城镇加工 -> 献祭/交付 -> 新探索
```

## 6. 首城建筑建议

### 6.1 初始 Home / 聚居地核心

定位：城镇基本经营中枢。

升级方向：

- 提升基础每日产出。
- 提升影响力上限或每日影响力产出。
- 解锁建筑管理。
- 提升城镇安定辐射范围。

初始 Home 不直接提供全部科技功能，只解锁管理权，具体服务仍由建筑或 NPC 承担。

### 6.2 酒馆

定位：知识、传闻、潜入支持和低级社交中心。

升级方向：

- Lv1：通识和少量秘闻。
- Lv2：增加秘闻刷新数量，解锁区域传闻筛选。
- Lv3：解锁针对特定地图的潜入提示或临时情报委托。

### 6.3 商亭 / 旧货交易点

定位：把搜刮物换成金钱，并提供通用贸易。

升级方向：

- 提升每日兑换额度。
- 增加物品用途提示。
- 解锁基础材料、补给品和加工辅料贸易。
- 提高对本城急需物资的收购价格。

### 6.4 木工棚

定位：首个生产型建筑和首条加工链。

升级方向：

- 增加加工配方。
- 提升每日加工批次。
- 减少加工时间或运营消耗。
- 解锁建筑修缮和献祭造物所需的木制品。

## 7. 通用建筑骨架、地方特性和城镇专属内容

三层叠加关系如下：

```text
通用建筑骨架 + 城镇/建筑地方特性 + 少量城镇专属内容
= 当前城镇的实际建筑
```

### 7.1 通用建筑骨架

所有酒馆共享通识、秘闻、捐献和社交服务；所有商亭共享估价、兑换和通用贸易；所有基础工坊共享加工、岗位和产出结算。

通用建筑还共享等级结构、经营方案槽位和基础界面。

### 7.2 地方特性

地方特性改变同类建筑的侧重点，不完全改变建筑类型。

`home_01` 酒馆可使用 `边境耳目`：

- 秘闻更偏向森林、怪物、偷猎者和野外路线。
- 通识产出较低但稳定。
- 升级后优先增加野外情报，而非贸易情报。

商路城镇酒馆可以使用 `商旅汇集`，教会城镇酒馆可以使用 `抄本传统`。地方特性由城镇或重要 NPC 提供，不需要玩家每日管理。

### 7.3 城镇专属内容

仅为确实属于某座城镇文化的内容单独配置：

- 独特 NPC 提供的情报或任务。
- 独特经营方案。
- 独特建筑或服务。
- 独特加工配方和贸易路线。

例如 `home_01` 酒馆可以在任务后解锁 `收留流民`，提高影响力和安定，但需要额外食物或布料。这是城镇故事内容，不应推广成所有酒馆都有的通用方案。

## 8. 城镇人口和 NPC 表现尺度

采用“宏观人口 + 关键 NPC”模式，不列出完整镇民姓名。

普通居民、工匠学徒、酒馆客人、商队成员和临时守卫以职业、数量和状态表示即可。

只有以下角色需要命名：

- 负责系统入口的人。
- 代表城镇立场的领导者。
- 提供独特科技、配方或服务的人。
- 与主线、好感或地图解锁绑定的人。

首城建议控制在 3 至 5 名核心 NPC。

## 9. 城镇对探索的支持

城镇支持分成安定、补给和情报三类，不全部转化为同一个百分比 Buff。

### 9.1 安定

由城镇控制度、建筑等级、科技节点和地方特性影响。

- 减少周边区域警戒累计速度。
- 提升潜入搜刮容错。
- 降低部分敌对巡逻或突发事件频率。

### 9.2 补给

由商亭、工坊和贸易功能提供，影响出发前准备和探索工具。

### 9.3 情报

由酒馆和重要 NPC 提供，提示高价值搜刮点、敌对势力、Boss、偷猎者和特殊采集点。

## 10. 配套界面方案

使用一个城镇管理入口，内部使用有限页签。

### 10.1 城镇总览

显示城镇状态、影响力、安定、已有建筑、科技解锁摘要和今日结算预览。

### 10.2 建筑

选择具体建筑后显示：

- 建筑等级和下一级效果。
- 升级成本。
- 当前经营方案。
- 可选经营方案和地方特性。
- 岗位、投入和产出。

建筑升级和经营方案是两个操作：升级是长期投资，经营方案是当前工作模式切换。

### 10.3 科技

显示社会组织、贸易与账册、工坊技术、情报与潜入四条早期分支。

每个节点显示：

- 解锁内容。
- 人类通识需求。
- 专精知识需求。
- 前置节点。
- 关联建筑或城镇条件。

首城科技节点数量控制在 8 至 12 个，避免第一次打开就看到完整文明树。

### 10.4 贸易与兑换

分成两个明确区域：

- `搜刮物兑换`：玩家主动选择物品换钱。
- `通用贸易`：使用金钱购买城镇商品。

两者不能合并成自动出售界面。玩家必须判断物品是卖掉，还是保留给加工、任务、献祭和收藏。

## 11. 首城第一批科技节点

### 社会组织

- `基础议事`：开放城镇总览和建筑管理。
- `影响力账册`：开放影响力显示和基础影响力产出。
- `地方安定`：开放城镇安定和周边辐射。

### 贸易与账册

- `旧货估价`：开放搜刮物手动兑换。
- `基础贸易`：开放金钱购买基础补给。
- `需求记录`：显示本城当前偏好的几类搜刮物或加工品。

### 工坊技术

- `简易木工`：开放木工棚第一批配方。
- `基础构件`：开放建筑和献祭使用的木制二级产物。
- `工匠分工`：提升加工批次或允许配置一个工坊经营方案。

### 情报与潜入

- `酒馆耳目`：开放秘闻产出。
- `边境传闻`：提高周边地图情报质量。
- `低调通行`：小幅减缓潜入警戒累计，不直接提供强力隐身。

## 12. 后续实现建议

第一轮不制作完整科技树，顺序如下：

1. 增加全局人类通识库存和城镇独立影响力状态。
2. 扩展现有城镇建筑等级数据，支持建筑经营方案。
3. 增加科技节点和前置条件读取，先配置 home_01 的 8 至 12 个节点。
4. 将商亭兑换、酒馆通识/秘闻和木工加工接入第一条经济链。
5. 在现有城镇管理 UI 基础上增加总览、科技、建筑、贸易四个页签。
6. 完成第一个献祭造物任务，再扩展第二座城镇的地方特性。

数据层优先复用现有 `HomesteadBuilding`、`HomesteadBuildingUpgrade` 和 `LogicAreaHomesteadPersist`。新增表只承载真正无法放入现有结构的内容：科技节点、建筑经营方案、地方特性和城镇影响力状态。

## 13. 设计约束

- 不自动分解或自动出售搜刮物。
- 不让人类通识取代金钱、影响力和专精知识的职责。
- 不让科技节点提供过大的全局百分比加成。
- 不增加需要玩家反复切换和维护的城镇管理层。
- 不为每个城镇复制完整建筑经营表。
- 不为普通镇民建立完整姓名、好感和任务数据。
- 不把首城做成所有生产和情报功能的终点。
- 城镇建设的收益要反馈到探索，但不能完全消除搜打撤风险。
