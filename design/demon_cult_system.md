# 教团系统（远古恶魔教义线）设计草案

## 1. 定位

教团系统是**独立于人类文明、主角既有养成**的第三条主线，同时作为二者的延申，并补齐主角「远古恶魔 / 莉莉丝」身份的玩法表达。

参照《咩咩启示录》（Cult of the Lamb）的骨架，但**不照搬信徒村庄经营**：

| 咩咩启示录 | 本项目教团 |
|------------|------------|
| 教义 / 戒律树 | **远古恶魔教义**（对标科技树，永久解锁） |
| 仪式（时效 / 冷却 / 消耗） | **恶魔仪式**（对标有时效的政策） |
| 信仰 | **信仰**（教团主货币） |
| 圣冠反哺战斗 | 教义反哺**主角本体能力** |
| 信徒日常经营 | **首期不做**完整信徒模拟；信徒感用抽象「教团势」或后期再开 |

一句话：

```text
人类文明「无处可去的副产物」→（高门槛献纳）→ 信仰
信仰 → 点教义（永久）+ 开仪式（时效政策）
教义 / 仪式 → 高风险反哺恶魔本体与禁忌玩法
```

### 1.1 经济定位（已定方向）

- **难度高、收益巨大**：教团是可选高风险高回报线，不是文明主循环的必经矿。  
- **吃副产物，不侵占正产物**：献纳对象应是文明体系里**原本缺乏终极去向**的边角产出（过剩加工品、劣质/污染造物、仪式边角料、异端抄本残页、探索带回但城镇消化不了的「亵渎可用」物等），而不是通识、关键专精、影响力、主线造物交付材料的主用途。  
- **人类通识 / 科技货币原则上不进献纳主通道**，避免教团把文明树掏空。  
- 教团是文明的**下水道 + 炼金炉**：让副产物有意义，同时逼玩家为巨大收益付出额外筹备与取舍。

---

## 2. 与现有系统的边界

| 系统 | 职责 | 与教团关系 |
|------|------|------------|
| **人类文明 / 科技树** | 通识、专精、城镇经营、人间秩序 | 提供**副产物池**；正产物仍优先文明自身 |
| **人类通识 `knowledge_shard`** | 人间知识货币 | **不作为**信仰主矿；至多作极少量象征性献纳或解锁条件 |
| **本体养成**（身体部位 / 符文 / 调精等） | 莉莉丝个人强度 | **输出端**：教义高收益反哺（须控通胀，见下） |
| **入梦 / 图鉴** | 魅魔侧收集与叙事 | 可作教义/仪式材料或条件，不并入主矿 |
| **秘密基地** | 据点设施与生活 | 教坛入口可挂据点，逻辑独立存档 |

原则：

1. **副产物原则**：先问「这东西文明主线还要不要」；要，就不进教团主通道。  
2. **账户独立**：信仰单独账户；不稀释通识。  
3. **解锁靠门槛**：资源与本体够强后再开。  
4. **高收益须配高门槛**：节点/仪式强度可以狠，但筹备副产物与冷却/互斥要狠。  
5. **不替代文明树**：人间秩序归科技；禁忌权能归教义。

---

## 3. 开放条件（建议）

全部满足（可调）：

1. **剧情**：明确「重拾旧教 / 立教」的叙事锚点（例如咕啾或旧契约 NPC 提示「月宫教义未灭」）。  
2. **资源**：人类文明侧已能稳定产出（如酒馆通识、基础加工、至少一次造物交付经验）。  
3. **本体**：Progression 强度过门槛（示例：身体部位总等级 / 已装备符文数 / 某主线战力标记）。  
4. **设施**：据点或指定场景出现「教坛 / 黑石祭台」交互点。

开放前只做世界观暗示，不做半残 UI。

---

## 4. 核心资源：信仰（Faith）

### 4.1 定义

- 教团唯一主货币，表示众生对莉莉丝神性的供奉浓度。  
- 存在于**教团账户**（存档独立字段），不是 `ItemStack` 杂物（展示可用 UI 货币条）。  
- 可有软上限（随教义「教座等级」提升），防止无限囤积稀释仪式决策。

### 4.2 主要来源（输入）

主通道 = **文明副产物献纳**，不是通识/影响力矿：

| 来源 | 说明 |
|------|------|
| **副产物献纳** | 城镇加工过剩品、品质偏差/污染造物、文明消化不掉的搜刮边角、异端残页等 → 信仰（需清单化「可献纳标签」） |
| **教坛日常** | 极低被动；仅防账户归零尴尬，不作养成主路径 |
| **仪式副产** | 少数仪式可回流信仰，但须消耗更稀缺副产物，防空转 |
| **身份行为** | 榨取/入梦等给「亵渎印记」类代币，再兑信仰或作节点材料；量少、强调身份 |

禁止：

- 野外无脑刷怪爆大量信仰。  
- 用人类通识、主线专精、地图解锁用关键造物当信仰主矿。  

设计时先给文明列一张「副产物 / 正产物」表，教团只挂副产物列。

### 4.3 主要去向（消费）

| 去向 | 说明 |
|------|------|
| **点亮教义节点** | 永久解锁，主消耗 |
| **发动仪式** | 一次性或维持型消耗；失败 / 中断可部分退回（可选） |
| **维持高阶仪式** | 时效政策期内的滴漏消耗（可选，防挂机叠满） |

## 5. 子系统 A：远古恶魔教义（对标科技树）

### 5.0 古老者之座（入口层）

教团 UI 在基础教义树之外，增加「古老者之座」入口层。世界上散落着一批刻有古老者形象的石碑；古老者是远古存在，名称与立场起初不区分正邪。莉莉丝通常被称为**原初恶魔**，是古老者中较特殊、也较强的一类；其他古老者可能更接近中立，但随着文明发展，许多古老者已经消失或沉睡。

- 每个石碑对应一个独立古老者入口，以及一组独立的教义节点。
- 王座入口的表现是石碑接受供奉，点亮一簇火团；火团节点亮起后，才向外延展该古老者的权能。
- 古老者可以与莉莉丝的过去发生交集，且不要求当前仍然存活。
- 首个入口为「淑女之座」：淑女掌管「往去」，是莉莉丝的核心淫纹之一，在故事开头已经死去；她的石碑与残存供奉构成第一个可进入的王座。
- 后续古老者座位可以处于已逝、沉睡、失联或未名状态，通过剧情、探索或信仰供奉解锁。

实现约束：基础教团树与古老者之座使用完全独立的配置表、节点表、运行时访问器和 UI。王座解锁状态与王座节点等级分开保存。

### 5.1 形态

- 多分支、节点解锁的**永久树**（视觉可做成碑文 / 血契树，区别于人类科技的「账册感」）。  
- 节点消耗：信仰为主；高阶可加「亵渎材料 / 契约残页 / 特定 EventGrant」。  
- 解锁条件：前置节点 + 可选剧情 / 本体门槛 / 文明阶段。

### 5.2 建议首期分支（4 条，控制表面积）

1. **神座与权能**  
   - 信仰上限、献纳汇率、教坛等级。  
   - 直接反哺：本体属性、恶魔技能槽、战斗倾向被动。

2. **血契与欲望**  
   - 榨取、亲密、入梦相关增益。  
   - 反哺：相关技能强度、冷却、收益；与既有魅魔玩法咬合。

3. **雾影与支配**  
   - 探索、潜行、区域压迫感、对魔物 / 人类的威慑。  
   - 反哺：FOV / 警戒修正、特定地图交互、召唤物上限（若已有召唤框架）。

4. **旧律与禁忌**  
   - 解锁更高阶**仪式**槽位与仪式种类。  
   - 少量永久规则改写（如献纳种类扩展、仪式冷却缩短）。

节点效果类型建议收束为：

- 永久属性 / 技能贡献（走 `IProgressionSkillSource` 一类既有接口）。  
- 解锁仪式或献纳配方。  
- 修改信仰经济参数（汇率、上限）。  
- **不做**「再造一套完整装备系统」。

### 5.3 与人类科技的对照感

| 人类科技 | 恶魔教义 |
|----------|----------|
| 通识 + 专精 | 信仰 + 亵渎材料 |
| 城镇变强、人间秩序 | 身份变强、禁忌秩序 |
| UI：书房 / 科技树 | UI：教坛 / 碑文 |
| 叙事：接入文明 | 叙事：重立旧教 |

两者可互相作为**解锁条件**（例如某人类科技后才能献纳某造物；某教义后献纳汇率提升），但**资源不混用同一钱包**。

## 6. 子系统 B：恶魔仪式（对标时效政策）

### 6.1 定义

仪式 = 消耗信仰（+ 可选材料），获得**有时限或有次数**的全局 / 区域 / 本人效果，到期失效或进入冷却。

对标咩咩的「仪式」，对本项目更接近：**可切换的政策卡**，而不是信徒 AI 演出全集。

### 6.2 仪式槽与互斥

- 同时生效仪式数量有限（例如 1～2 条，随教义增加）。  
- 同组互斥（丰饶 vs 苛索、隐匿 vs 威压）。  
- 冷却：真实游戏日或 LogicTime；菜单暂停是否冻结与全局时间规则对齐。

### 6.3 仪式效果方向（示例，首期少做精）

| 类型 | 示例效果 | 备注 |
|------|----------|------|
| **丰饶转化** | 一段时间内文明献纳汇率 ↑ | 强化「文明 → 信仰」循环 |
| **血宴** | 榨取 / 击杀回信仰或本体临时加成 | 身份向 |
| **雾帷** | 潜入警戒下降 / 夜行增益 | 探索向 |
| **威压布道** | 区域魔物弱化或掉落修正，但献纳效率 ↓ | 有取舍的政策感 |
| **旧月显圣** | 短时强力战斗 Buff，冷却长 | 高光按钮，防日常刷 |

仪式**不**替代 Buff 系统全部内容；优先做「经营 / 节奏选择」向的宏观修正，战斗 Buff 可挂既有 Buff 定义。

### 6.4 仪式与教义的关系

- 教义解锁仪式种类、槽位、降低消耗 / 冷却。  
- 仪式不永久点树；关了就没，逼玩家做时段选择（政策感）。

---

## 7. 主循环（玩家体验）

```text
探索 / 经营人类侧
    → 获得通识、造物、影响力
    → 在教坛献纳 → 信仰
    → 点远古教义 → 本体变强 / 解锁仪式
    → 发动仪式 → 时段内转化效率或战斗探索增益
    → 带着增益再去探索 / 经营 → 更多可献纳产出
```

节奏预期：

- **日常**：小额献纳 + 维持 1 个温和仪式。  
- **爆点**：攒信仰点关键教义，或开高冷却仪式打困难内容。  
- **身份感**：UI、文案、演出偏「旧月教廷」，与人类书房科技明确分家。

## 8. 内容载体与入口

| 载体 | 作用 |
|------|------|
| **据点教坛设施** | 主 UI：信仰、教义树、仪式、献纳 |
| **地图交互点**（可选） | 野外简陋祭坛，仅献纳或单次仪式 |
| **NPC**（后期） | 咕啾 / 旧部下解说教义；不强制第一期 |

首期 UI 建议单 Panel 三分页：`献纳` / `教义` / `仪式`，避免枢纽 Tab 膨胀；入口挂秘密基地设施即可。

---

## 9. 存档与配置原则（设计约束，不落库）

- 存档：信仰值、已点教义 id、当前仪式状态（id、剩余时间、冷却）、献纳统计（可选）。  
- 配表：教义节点表、仪式表、献纳配方表；效果尽量复用属性加成 / Buff / 既有 Progression 贡献，少造平行数值系统。  
- 开放条件走 FuncOpen 或任务变量，与文明阶段解耦配置。

---

## 10. 明确不做（首期）

1. 完整信徒个体模拟（饥饿、叛教 AI、宿舍排班）。  
2. 用信仰购买普通装备商店。  
3. 与人类科技共用同一点树或同一货币。  
4. 开局即开放教团，冲淡 home_01 生存与人间盟约叙事。  
5. 把教团做成第二个秘密基地建造玩法。

信徒人数、布道小游戏等留作**二期可选扩展**。

---

## 11. 分期建议

### 第一期（竖立循环）

- 信仰账户 + 献纳（通识 / 少数造物）。  
- 教义树 1～2 条短枝（神座 + 旧律）。  
- 仪式 2～3 个（转化增益 + 战斗 / 探索各一）。  
- 据点教坛 Panel。

### 第二期（身份补齐）

- 血契 / 雾影分支。  
- 仪式互斥组与政策感加强。  
- 与入梦、榨取、主线「旧月」叙事挂钩。

### 第三期（可选）

- 抽象「教团势」或轻量信徒。  
- 跨地图教廷事件、异端冲突。

---

## 12. 待拍板问题

1. 首期「副产物」具体清单（建议从加工过剩品 + 污染/异端搜刮物起）。  
2. 信仰软上限与每日献纳硬上限是否都要？  
3. 仪式时间绑 LogicTime 还是现实时间？  
4. 高收益反哺：只被动 Progression，还是含主动技能 / 禁忌交互？幅度上限？  
5. 叙事上对村民：公开立教 vs 暗中旧教？  
6. 地图解锁用「造物交付」与教坛献纳：严格分列，还是部分失败品/多余品可改献教坛？

---

## 13. 结论

教团系统 = **信仰经济** + **永久教义树** + **时效仪式政策**，挂在恶魔身份上，吃人类文明产出，吐回主角强度与探索节奏选择。

它延申人类文明（产出有终极去向），延申本体养成（多一条制度性变强），并补齐「莉莉丝不只是变强的个体，而是可立教的远古存在」的玩法空缺；同时用「不做信徒模拟」控制首期复杂度，避免与据点 / 城镇经营三重叠床。

## 14. 首期落地切片（已实现骨架）

配置：

- `Config/Datas/cult_tech.xlsx` → `TbCultTechNode` / `TbCultTechNodeLevel`，只包含基础教团树
- `Config/Datas/cult_ancient_seat.xlsx` → `TbCultAncientSeat` / `TbCultSeatTechNode` / `TbCultSeatTechNodeLevel`，只包含古老者之座及其子树
- 节点用 `ring` + `angle_deg` 描述径向布局（0 = 中心）
- 等级消耗为 `faith_cost`；效果暂用 `effect_desc` 占位文案

运行时：

- `DemonCultPersist`（信仰 + 节点等级）写入 `SaveData`
- `DemonCultSystem`：信仰收支、前置校验、解锁、`CultTechNodeVisualState`
- 挂在 `PlayerProgressionSystem.DemonCult`，随 `PlayerSystemManager.SaveTo` 落盘
- 新档默认点亮「教座之心」并给 100 信仰便于调试

UI：

- `CultTechTreePanel` / `CultTechTreeView` / `CultTechNodeView`
- 基础树预制体：`UI/Prefabs/PlayerProgressionHubPanelSub/CultTechTreePanel`
- 王座树预制体：`UI/Prefabs/PlayerProgressionHubPanelSub/AncientSeatTreePanel`
- 中心外扩连线；右侧详情 +「铭刻」按钮
- GM：`cult_ui` 打开面板；`add_faith <n>` 加信仰

未做：献纳配方、仪式、真实效果数值、据点教坛入口、开放条件。
